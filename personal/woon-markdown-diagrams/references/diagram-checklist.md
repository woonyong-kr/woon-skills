# Diagram checklist

- One diagram answers one explicit question.
- Diagram type matches the relationship being explained.
- No more than 9 overview nodes and 3 short lines per node.
- Korean explanation with exact original technical identifiers.
- No hard-coded colors or red/green-only meaning.
- No crossing lines or clipped text in the available preview.
- Precondition appears before the dependent step.
- Mermaid source remains inside the canonical Markdown file.
