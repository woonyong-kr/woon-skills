# 한국어 문장 교정 기준

아래 표현은 문맥을 살펴볼 신호다. 단어 하나가 나타났다고 잘못된 문장으로 판정하지 않는다. 사용자 말투, 글의 용도와 검증 가능한 원뜻이 우선한다.

## 근거와 주장

- **과장**: `혁신적인`, `강력한`, `완벽한` 같은 평가를 뒷받침하는 동작·결과가 있으면 그것을 쓴다. 원문에 없는 장점이나 숫자는 만들지 않는다.
- **모호한 권위**: `전문가들에 따르면`의 출처를 확인한다. 없으면 권위를 덧씌우지 말고 확인된 범위로 설명한다.
- **정보 부족 뒤의 추측**: 아는 사실과 추론을 구분한다. 확인되지 않은 원인이나 날짜를 문장 교정 중 확정하지 않는다.
- **상투적 기대**: `앞으로의 행보가 기대된다` 대신 실제 다음 행동이 원문에 있을 때 그것을 남긴다. 감정 기록의 기대는 지우지 않는다.
- **완곡 표현 중첩**: `상당히 … 할 수 있을 것으로 보인다`를 줄여도 원래의 불확실성은 남긴다.

## 번역투와 어휘

- **접속어 반복**: `또한`, `이를 통해`가 없어도 이어지면 덜어낸다. 인과·대조·조건을 담고 있다면 그 관계를 보존한다.
- **불필요한 외래어**: 독자에게 더 명확할 때만 바꾼다. `API`, `gradient`, `coroutine`처럼 실제 학습·검색에 쓰는 말은 유지한다.
- **동의어 돌려쓰기**: 같은 대상을 `사용자`, `고객`, `클라이언트`로 번갈아 부르지 않는다. 서로 다른 역할이면 구분을 유지한다.

## 주체와 동작

- **명사 나열**: `효율성 향상을 위한 최적화의 수행`처럼 동작을 감춘 명사구를 주어와 동사로 풀어 쓴다. `정규화`, `안정성` 같은 개념명 자체를 금지하지 않는다.
- **수동태·가능 표현 반복**: 실제 주체가 확인될 때만 드러낸다. `할 수 있다`가 기능이나 가능성을 뜻한다면 실제로 수행한다는 문장으로 바꾸지 않는다.

예를 들어 `설정 변경이 가능하며 결과는 자동으로 저장됩니다`는 사실이 같다면 `설정을 바꾸면 결과가 자동으로 저장됩니다`로 고친다. 저장 주체를 모르면 임의로 이름 붙이지 않는다.

## 말투와 독자

- **문체 혼합**: 설명 중 `-다`, `-해요`, `-합니다`가 이유 없이 섞이면 맞춘다. 인용·코드 주석·등장인물 대사의 말투는 별개다.
- **대화 잔재**: 완성 글의 `좋은 질문입니다`, `아래와 같이 정리해 드립니다`를 덜고 내용부터 쓴다.
- **과한 공손함**: `확인하시어 참고 부탁드립니다`를 `확인해 주세요`처럼 용도에 맞게 줄인다. 실제 편지의 예의나 감정은 보존한다.
- **맞장구·과장된 솔직함**: `정확히 보셨습니다`, `솔직히 말하면`이 내용 없이 분위기만 만들면 줄인다.

## 구조와 호흡

- **형식만 남은 목차**: 짧은 글을 매번 요약·효과·결론으로 나누지 않는다. 책 목차와 키워드 트리는 탐색 구조이므로 이 이유로 없애지 않는다.
- **문장 부호 과밀**: 괄호·슬래시·콜론이 의미를 가리면 문장을 나눈다. 날짜 구간, 수식, 단위, 코드와 링크에는 적용하지 않는다.
- **제목 되풀이**: 제목 다음의 `이제 … 알아보겠습니다`가 안내만 반복하면 실제 설명부터 쓴다. 학습에 필요한 질문은 보존한다.
- **굵은 라벨 반복**: 매 줄 `**핵심:**`처럼 꾸미지 않는다. 비교 항목이 고정된 표나 설정 목록은 유지한다.
- **변경 사실로만 설명**: 현재 기능을 설명하는 글은 지금의 동작을 쓴다. 변경 이력·일기·사건 기록의 시점을 현재로 바꾸지 않는다.
- **획일적인 호흡**: 모든 문장을 같은 길이로 자르지 않는다. 같은 주체·직접 인과는 이어 쓰고, 주체·시점·판단이 바뀌면 나눈다. 끝맺음만 억지로 다양화하지 않는다.

## 국어 자료

용어 선택이나 표기 이유를 설명해야 할 때 필요한 자료만 확인한다. 조회하지 않은 말뭉치나 기관의 평가를 근거로 주장하지 않는다.

- [국립국어원 공공언어](https://www.korean.go.kr/front/support/supportIntro.do?mn_id=163): 일반 독자가 이해할 표현.
- [다듬은 말](https://www.korean.go.kr/front/imprv/refineList.do?mn_id=158): 독자에게 명확한 대안인지 검토하는 참고자료.
- [표준국어대사전](https://stdict.korean.go.kr/main/main.do), [어문 규범](https://korean.go.kr/kornorms): 뜻·맞춤법·띄어쓰기·외래어 표기.
- [우리말샘](https://opendict.korean.go.kr/main): 새로운 용례를 찾는 보조 자료. 공식 표기가 필요하면 사전·규범으로 재확인한다.
