# Lookup

package name과 설치된 version을 manifest·lockfile·runtime에서 확인한다. 공식 documentation, API reference, release note, migration guide, source repository를 우선하고 블로그는 보조로만 쓴다.

질문과 관련된 section만 읽고 version별 차이를 분리한다. 예제는 현재 저장소 언어·version에 맞게 최소화하며 deprecated API를 섞지 않는다. 답변에는 확인한 version, 공식 링크, 적용한 해석, 아직 검증하지 못한 부분을 남긴다.
