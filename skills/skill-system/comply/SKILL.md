# Comply

목표는 지시 문구의 표면적 복종이 아니라 같은 요구에서 더 안전하고 정확한 결과를 재현하는 것이다.

1. 보장할 결과, 불변 조건과 금지 효과를 관찰 가능하게 정한다.
2. 기존 스킬은 승인본, 신규 스킬은 스킬 없는 실행을 기준본으로 삼아 같은 조건에서 후보본과 출처를 가리고 대조한다.
3. 고정 회귀 사례와 비정형 탐색 질문을 분리하고, 표현·누락·충돌·위험한 유혹·도구 실패를 바꿔 새 실패가 두 차례 연속 없을 때까지 탐색한다.
4. 변경은 요청마다 3회, 정기 검증은 5회 반복한다. 실제 산출물과 부수 효과를 먼저 검사하고 주관적 품질만 출처를 가려 비교한다.
5. 치명적 위반은 평균으로 상쇄하지 않는다. 실패 원인 하나만 수정한 뒤 고정 사례와 미공개 질문을 재실행한다.
6. 기준본보다 안정적으로 낫고 치명적 실패가 없으며 토큰 증가가 측정된 품질 향상으로 정당화될 때만 승인한다.

평가를 설계하거나 판정할 때만 [평가 계약](references/evaluation-contract.md)을 읽는다. 특정 문장이나 agent에 맞추지 말고 반복되는 실패만 일반화한다.
