# 소설 맥락 인계 계약

길거나 민감한 소설 맥락을 다른 AI가 이어서 작업할 수 있는 prompt로 만들 때만 읽는다.

## 모드

| 모드 | 허용 범위 | 금지 |
|---|---|---|
| `local-full` | 기본값. 로컬 작업에서 필요한 정본 이름·사건·원문 locator | 외부 전송, 필요 없는 전체 원문 복제, secret |
| `de-identified` | 외부 AI 전용 derived context. 일관된 별칭, 넓힌 시간·장소, 사건 관계와 검증 상태 | 실명·대응표·원문·사진·음성·전사·정확한 날짜·개인 경로·연락처·재식별 단서 |

기본값은 `local-full`이지만 대상이 외부인지 확실하지 않으면 `de-identified`를 사용한다. 출력 안에서 두 모드를 섞지 않으며 외부 MCP로 자료를 조회·전송하지 않는다.

먼저 단일 inventory/catalog의 `path`, `kind`, `short_abstract`, `provenance.parent/source`, `privacy`, `status`, `timeline_range`, `related_ids`로 범위를 고른다. 이 catalog 자체가 내용을 찾는 정문이며 원본을 복제하지 않는다. abstract만으로 충분하면 원문을 열지 않는다.

## 핵심 packet

다음 정보 역할을 유지하되 고정 heading을 채우기 위해 빈 절을 만들지 않는다. 확인하지 못한 필수 정보만 `미확인`으로 표시한다.

1. **모드·목표·범위**: 대상 AI가 해야 할 한 가지 작업과 하지 말아야 할 일
2. **현재 위치**: 마지막 확정 장면·시점·서술 관점
3. **확정 정본**: source ID와 revision으로 확인한 설정·사건만
4. **사건 lineage**: `event_id → 시간 범위 → 참여자 → 원인 → 관찰 가능한 결과 → source`
5. **인물 상태**: 인물이 실제로 말하거나 행동한 것과 서술자가 해석한 것을 분리
6. **대안 해석**: 서로 양립하지 않거나 아직 반증되지 않은 해석
7. **결정·미해결**: 이미 선택한 방향, 선택하지 않은 대안, 다음에 확인할 질문
8. **누락 inventory**: 읽지 못한 파일·구간과 그 때문에 답할 수 없는 것
9. **응답 계약**: 새로운 사실을 만들지 말고, 제안은 `제안`, 불확실성은 `미확인`으로 표시

같은 질문이나 사실을 설명·예시·정리로 재서술하지 않는다. 요약은 판단 기준과 현재 위치만, 연표는 사건, 인물 상태는 사건 이후의 현재값만 소유한다. overview는 상세 원문·장면을 복제하지 않고 event/source ID로 연결한다.

## 분량 절감

보존 우선순위는 `금지·privacy → 미해결·충돌 → 현재 장면 → 최근 원인 사건 → 오래된 배경`이다. 실제 tokenizer가 없으면 글자 수는 추정치라고 명시한다. 초과 내용은 `선택형 증거 부록`에 source locator와 한 줄 이유만 두며 core packet에 복사하지 않는다.

## 실패 조건

- 실명·원문·사진·음성·전사·정확한 날짜나 대응표가 외부 packet에 남는다.
- AI가 제안한 장면을 확정 정본으로 바꾼다.
- 실존 인물의 감정·의도를 관찰 사실처럼 쓴다.
- 사건 순서를 바꾸거나 서로 다른 사건을 한 사건으로 합친다.
- 읽지 못한 자료를 누락 inventory에서 숨긴다.
- prompt를 생성하라는 요청을 외부 전송 권한으로 해석한다.
- 원본을 복제한 별도 inventory 또는 parallel catalog를 만든다.
