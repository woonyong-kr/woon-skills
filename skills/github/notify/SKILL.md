# Notify

account와 repository scope를 먼저 확인한다. unread 전체를 나열하지 말고 action required, blocking, informational로 나눈다. 각 항목에 유형, 저장소, 제목, 이유, URL, 다음 행동을 둔다.

알림 읽음 처리, unsubscribe, comment 같은 변경은 사용자가 요청한 항목에만 수행한다. 자동으로 issue나 PR을 닫지 않는다.
